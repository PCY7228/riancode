ตัวแปรและชนิดข้อมูล (Variables & Data Types)

ในภาษา Python การสร้างตัวแปรทำได้ง่ายมาก! คุณไม่ต้องประกาศชนิดข้อมูลล่วงหน้าเหมือนภาษาอื่น เพียงตั้งชื่อตัวแปร แล้วใช้เครื่องหมายเท่ากับ = กำหนดค่าได้ทันที

💡 ข้อควรจำที่สำคัญ: ชื่อตัวแปรใน Python ควรเป็นภาษาอังกฤษ ห้ามขึ้นต้นด้วยตัวเลข และไม่ควรเว้นวรรค (สามารถใช้ _ เชื่อมคำได้ เช่น user_name)

ตัวอย่างการเขียนโค้ดในบทเรียนนี้:

python # 1. ข้อความ (String) name = "Somchai" # 2. จำนวนเต็ม (Integer) age = 20 # 3. ทศนิยม (Float) score = 98.5 # 4. ค่าความจริง (Boolean) is_passed = True

🎯 ภารกิจลองทำ (Task):

ลองแก้ไขโค้ดที่หน้าจอฝั่งขวามือ ให้ตัวแปร name เป็นชื่อของคุณ และ score เป็น 100 จากนั้นกดปุ่ม ▶️ รันโค้ด เพื่อทดสอบผลลัพธ์!
